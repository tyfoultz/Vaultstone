Vaultstone · Mockup Review

Manage Spells — Modal Concepts

Four alternate layouts for the Manage Spells modal on the character sheet's Spells tab. All four use Vaultstone's Magical Midnight Noir palette, Space Grotesk + Manrope, and sample spells across cantrip / 1st / 2nd / 3rd levels. Click any card to open the standalone mockup.

01

Spellbook

PHB-style two-pane reader: collapsible level-grouped tree on the left, full spell detail on the right with one click — fewer round-trips for power users.

Two-pane Tree nav Detail-rich
02

Card Grid

Filterable grid of richer spell cards with school glyph, casting/range line, concentration/ritual badges, snippet preview, and inline "+ Add" — no detail click required.

Grid Inline add Visual-forward
03

Dense Table

Single-screen sortable table — Name, Lvl, School, Casting, Range, Components, Conc, Ritual, Add. Click row to expand description inline. Optimized for scanning a lot of spells fast.

Table Sortable Information-dense
04

Split View

Catalog on the left, prepared list on the right. Tap to add, X to remove. Each pane scrolls independently; filters apply only to the catalog. Fastest for "build a loadout from scratch."

Two-pane Loadout Slot tracker
