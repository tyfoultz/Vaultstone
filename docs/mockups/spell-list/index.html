Vaultstone · Mockup Review

Prepared Spells — List Concepts

Six alternate layouts for the prepared spells list on the character sheet's Spells tab. All six use Vaultstone's Magical Midnight Noir palette plus Space Grotesk + Manrope (with serif accents on #3 / #4 / #5). Same sample loadout across every mockup — cantrips, three 1st-level spells (3 / 4 slots), two 2nd-level spells (2 / 2 slots) — so visual comparisons are direct.

01

Clean Rows

Clean, modern hairline-separated rows. Name + school chip + optional badges in the header, one-line meta strip with labels, indented description. No table headers, no duplicate fields.

Borderless Modern Always-expanded
02

Bordered Cards

Same content as #01 but each spell wrapped in a rounded surface card. Heavier separation reads as a "stat block" feel, and hover lifts each row distinctly.

Card-based Hoverable Always-expanded
03

Spellbook — Parchment

Aged-parchment slab on the dark canvas. Italic IM Fell English spell names, Cinzel level dividers with ornamental flourishes, glowing slot stones, drop-cap descriptions. Immersive PHB feel.

Immersive Serif Parchment
04

Spellbook — Arcane Tome

Dark moody tome instead of parchment. Purple-tinted gradient, Uncial Antiqua / MedievalSharp display serifs with a soft glow, sigil glyphs flanking section headers, glowing rune-stone slot pips. Same content as #03 but moodier.

Immersive Arcane On-brand purple
05

Grimoire Side-Tabs

Vertical level tabs running down the spine, parchment page on the right showing only the selected level. Mimics flipping pages in a grimoire — great for casters with deep loadouts who don't want to scroll past every level.

Side-tabs One level at a time Interactive
06

Compact List

Information-dense two-line rows for fast scanning. Click a row to expand the full description & meta grid. Both collapsed and expanded states shown side-by-side. Good for high-prepared-count loadouts.

Dense Click-to-expand Scan-first
Currently shipped: always-expanded blocks with a redundant table header row + inline meta grid that duplicates the table columns + the description. These six explore cleaner alternatives ranging from minimal modern (#01-#02) to immersive spellbook (#03-#05) to information-dense (#06).
