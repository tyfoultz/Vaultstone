Quick actions
Desktop changes worth reacting to
  • Vitals strip moved up to live directly under the identity row — HP, AC, Init, Speed, Prof. Most-glanced data is always in the same spot regardless of tab.
  • Ability rail stays narrow on the left, saves shown via accented border + colored mod. No separate "Saves" sub-section needed.
  • Right rail now carries campaign context + recent activity log + quick rest buttons. Replaces the current Skills-on-the-right pane.
  • Level-up is an accented icon in the action rail — the chip displays the current level so the tap target is unambiguous.
  • Tab dots show "owed picks" (e.g. unspent cantrips on Spells) without expanding the tab.
Direction still up for grabs
  • Whether the right rail should be collapsible (currently always-on).
  • Where the "edit name / portrait" affordance lands — currently nowhere visible.
  • Inspiration as a glow-pip vs an explicit toggle.
  • How the Conditions row should behave at scale (16+ conditions): chip wrap as shown, or a separate modal.

Mobile changes worth reacting to
  • Header compresses portrait + name + level-up into one row. Identity stays compact so vitals + abilities fit on first scroll.
  • Ability row scrolls horizontally — six tiles, swipable, less vertical real estate than a 2×3 grid.
  • Skills shows top 8 by default, expand button reveals the full 18. Most sheets are read-only browsing for skills; the long list is rarely scanned in full on phone.
  • Bottom tab bar is sticky, replaces the current top tab strip — same Core/Spells/Traits/Gear/Lore.
  • Conditions collapse to active-only + a "+ N more" affordance to open a sheet picker.
What I deliberately didn't change
Tab structure stays as the new Core/Spells/Traits/Gear/Lore set. Section content (actions, skills, conditions, etc.) is the same data your tabs already render. The polish is in density, hierarchy, accent treatment, and stickiness of vitals — not in adding or moving features.
