Layout Explorations

Four distinct layout philosophies. Each answers a different question about what should always be visible vs. what lives behind a tab. Mobile and web shown side by side. All use the Noir token palette.

Option A

The Stat Spine

A narrow left rail (200px) permanently shows everything you need to reference mid-session: ability scores, saving throws, HP, and combat stats. You never lose your bearings while browsing tabs. Content area is clean and focused. Ability scores always visible means the web layout acts like a physical character sheet folded open.

Option B

The War Room

A pinned full-width HUD strip at the top always shows the most critical combat data: portrait, name, HP bar, AC, Initiative, Speed, Prof — and short/long rest buttons. Below that, a narrow icon sidebar handles tab navigation on web. Maximum content space. Feels like a command interface. Rest buttons visible at all times.

Option C

The Folio

The character's portrait is given real estate — a large art panel on the left, like a character folio or journal spread open. Name overlays the art at the bottom. Stats sit below the art in a tight block. On mobile, the art is a banner at top with a gradient dissolve into the stats. The most visually distinctive option — trades some utility for character immersion.

Option D

The Codex

Navigation lives in a labeled left sidebar — not icon-only, not top tabs, but a proper nav panel like VS Code or a native Mac app. Portrait + HP in the nav header. The content area gets a section title and contextual actions (like an Add button for spells). On mobile it collapses to bottom tabs as usual. The most "app-like" of the four options. Clean, familiar, and scales well as you add more tabs.
